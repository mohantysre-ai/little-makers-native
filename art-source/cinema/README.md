# Moon film source

The bundled clips are excerpts of the title-free NASA SVS 4619 lunar scientific visualization. The upstream source remains available at https://svs.gsfc.nasa.gov/4619/. The original VP8 WEBM was downloaded for production but is not redundantly checked into this repository. The source soundtrack was absent; all packaged MP4 files are video-only. See the manifest for source URLs, exact in-points, transformations and SHA256 checksums. NASA and its contributors do not endorse Little Makers. This is factual educational use; no agency logo or identifiable person was packaged.
