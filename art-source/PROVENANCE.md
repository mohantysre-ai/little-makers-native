# Village artwork

One original image generated using the built-in image-generation tool, then converted to WebP for the app. Prompt: Wide 1536x1024 handcrafted matte clay/stop-motion miniature island village, cream sky, lush rounded terrain and winding sandy paths. Friendly terracotta dormant volcano upper left, painting easel upper right, leafy story treehouse lower right, blue observatory lower left, central clearing. Warm muted colors, soft daylight, handmade textures. No text, UI or watermark.

## v1.7 vector village and motion
The active Home background is now `dist/world.svg`, an original code-authored vector landscape. `dist/buddy.svg` is an original geometric companion. The former generated WebP remains in the source for provenance but is no longer the Home background. `dist/motion/creation_saved.json` is an original 0.8-second vector Lottie composition with no raster assets. Destination, avatar and sticker illustrations reuse the credited OpenMoji library. Lottie Web is MIT-licensed; its notice is included in `dist/motion/LOTTIE-LICENSE.txt`.
